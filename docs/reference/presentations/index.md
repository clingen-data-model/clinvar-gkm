# Presentations

Slide decks for introducing and explaining ClinVar-GKM to different audiences. Each deck is a self-contained,
interactive HTML presentation that runs in the browser — navigate with the arrow keys, and press `?` inside a
deck for the full list of shortcuts.

## Available presentations

| Presentation | Event | Audience | Length |
| --- | --- | --- | --- |
| [ClinVar-GKM Primer](clinvar-gkm-primer.md) | GA4GH Connect · Oct 2, 2026 | Technical teams familiar with ClinVar but new to VA-Spec / the GKM model | ~8 min (15 slides) |

!!! tip "Presenting from a deck"
    Open a presentation, then use its fullscreen launch link for a clean, full-window view. Inside a deck,
    press `S` for speaker notes, `T` to toggle light/dark, and `F` for fullscreen.
