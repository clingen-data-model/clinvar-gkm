ClinVar-GKM bundle — class relationships

release bundle sections

How the bundle's classes reference one another, grouped by section. Statements assert a Proposition; a proposition's subject is a variant and its object is a condition; variants resolve down to VRS alleles and locations. Arrows point from the class that owns the reference to the class it targets; dashed arrows are optional/conditional. Every box links to its class page.
