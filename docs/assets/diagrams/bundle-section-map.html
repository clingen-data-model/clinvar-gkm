The release bundle is a single JSON object of named sections; each section is a dictionary mapping a typed id to one object. Objects link across sections with #/section/id JSON pointers — each drawer lists its outgoing references as field → #/section/. Boxes link to the class reference; see the ID References page for the full pointer catalog.
