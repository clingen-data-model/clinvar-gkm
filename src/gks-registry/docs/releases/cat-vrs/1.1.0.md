## Schemas

| Schema | Maturity | Description |
|--------|----------|-------------|
| [AdjacencyConstraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/AdjacencyConstraint) | draft | Components that define a molecular adjacency of congruent elements. |
| [CanonicalAllele](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/CanonicalAllele) | trial use | A canonical allele is defined by an Allele that is representative of a collection of congruent Alleles, each of which depict the same nucleic acid on different underlying reference sequences. Congruent representations of an Allele often exist across different genome assemblies and associated cDNA transcript representations. |
| [CategoricalCnv](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/CategoricalCnv) | draft | A representation of the constraints for matching knowledge about CNVs. |
| [CategoricalVariant](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/CategoricalVariant) | trial use | A representation of a categorically-defined domain for variation, in which individual Constraintual variation instances may be members of the domain. |
| [Constraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/Constraint) | trial use | Constraints are used to construct an intensional semantics of categorical variant types. |
| [CopyChangeConstraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/CopyChangeConstraint) | draft | The relative assessment of the change in copies that members of this categorical variant satisfy. |
| [CopyCountConstraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/CopyCountConstraint) | trial use | The exact or range of copies that members of this categorical variant must satisfy. |
| [DefiningAlleleConstraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/DefiningAlleleConstraint) | trial use | The defining allele and its associated relationships that are congruent with member variants. |
| [DefiningLocationConstraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/DefiningLocationConstraint) | trial use | The defining location and its associated relationships that are congruent with member locations. |
| [FeatureContextConstraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/FeatureContextConstraint) | draft | The feature that members of this categorical variant are associated with. |
| [FunctionConstraint](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/FunctionConstraint) | draft | A classification of the protein functional consequence that characterizes members of this categorical variant. |
| [FunctionVariant](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/FunctionVariant) | draft | A representation of the constraints for matching knowledge about function variants; e.g., gain-of-function or loss-of-function. |
| [FunctionalDomain](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/FunctionalDomain) | draft | A sequence location whose presence or absence is used to define an adjacency. |
| [GeneFusion](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/GeneFusion) | draft | A representation of the joining of two genes resulting in a chimeric transcript and/or novel interaction between a rearranged regulatory elements with the expression of a partner gene product (a regulatory fusion). |
| [ProteinSequenceConsequence](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/ProteinSequenceConsequence) | trial use | A change that occurs in a protein sequence as a result of genomic changes. Due to the degenerate nature of the genetic code, there are often several genomic changes that can cause a protein sequence consequence. The protein sequence consequence, like a CanonicalAllele, is defined by an Allele that is representative of a collection of congruent Protein Alleles that share the same altered codon(s). |
| [UnspecifiedElement](https://github.com/ga4gh/cat-vrs/blob/1.1.0/schema/cat-vrs/json/UnspecifiedElement) | draft | Represents an unspecified element that satisfies the described adjacency. |
